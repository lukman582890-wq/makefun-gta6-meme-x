## Running Locally

```bash
mkdir -p out
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` validates `POST.json` offline using the Node 22+ standard library and writes the normalized manifest deterministically to `/output/POST.json`.
